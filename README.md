# Diia GUI Shell

Android Studio проект с GUI-only главной страницей, перенесенной по открытым исходникам `diia-open-source/android-diia`.

## Что перенесено

- Верхняя панель главного экрана из `home`: логотип Diia, заголовок вкладки `Стрічка`, кнопка QR-сканера.
- Стартовая вкладка `Стрічка`, потому что в оригинальном `HomeF.kt` она указана как `startDestination = ScreenFeedRoute`.
- Offline-содержимое feed из open-source проекта: приветствие `Привіт 👋`, кнопка `Сканувати QR-код`, карточка `Незламність`.
- Нижняя навигация home с четырьмя пунктами из оригинального `HomeBottomBar`: `Стрічка`, `Документи`, `Сервіси`, `Меню`.
- Вторая статичная вкладка `Документи`, основанная на `DocGalleryC`, `DocGalleryVMCompose` и `DocumentComposeMapperImpl`: визуальный DocCarousel/DocCard для водительского удостоверения, переключатели `QR-код` / `Штрихкод`, пункты `Додати документ` и `Змінити порядок документів`.
- Переключение между `Стрічка` и `Документи` через нижнюю панель без навигационного backend и без загрузки данных.
- Векторные ресурсы Diia (`ic_logo_diia`, `ic_qr`, tab icons) скопированы из open-source репозитория.

## Что удалено / не подключено

Проект является только оболочкой интерфейса. Здесь нет авторизации, backend-запросов, новостей, платежей, аналитики, QR-сканера, генерации штрихкодов, PDF/share, runtime permissions, Hilt, Compose-навигации и бизнес-логики оригинального приложения.

## Как открыть

1. Откройте этот каталог в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на эмуляторе или устройстве.
