# Diia GUI Shell

Небольшой Android Studio проект с GUI-only оболочкой в стиле мобильного приложения Diia. Проект предназначен для прототипирования интерфейса: в нем нет авторизации, backend-запросов, платежей, QR-проверок, аналитики или хранения пользовательских данных.

## Что внутри

- Один модуль Android-приложения `:app`.
- Один экран `MainActivity` со статичной XML-разметкой.
- Только локальные ресурсы Android (`layout`, `drawable`, `values`).
- Нет runtime permissions и сетевых разрешений.

## Как открыть

1. Откройте этот каталог в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на эмуляторе или устройстве.

## Ограничения прототипа

Все документы, сервисы и данные на экране являются демонстрационными заглушками. Элементы интерфейса специально не подключены к обработчикам действий, API или backend.
